# JEYSHREE CATERING — LANDING INTRO FOLIAGE ASSETS

This directory is reserved for custom banana tree / plantain foliage images.

## How to replace foliage images:
The landing intro already includes realistic South Indian plantain foliage vectors out-of-the-box.
If you have your own high-resolution transparent PNG cutouts (e.g. from Photoshop or your photographer),
you can simply place them here with these exact file names:

- `banana-left-fg.png`   (Left side foreground leaf / crisp details)
- `banana-left-mid.png`  (Left side middle foliage)
- `banana-left-bg.png`   (Left side background foliage / deeper shadow)

- `banana-right-fg.png`  (Right side foreground leaf / crisp details)
- `banana-right-mid.png` (Right side middle foliage)
- `banana-right-bg.png`  (Right side background foliage / deeper shadow)

## Specifications:
- Format: Transparent PNG or WebP
- Recommended Dimensions: ~600px width × ~1200px height
- Background: 100% transparent alpha channel
